You are given a text and a list of strings. For each string in the list, you need to find its first occurrence in the text. However, matches across word boundaries in the text are allowed.

Consider the text the quick brown fox jumps over the lazy dog and the strings quic, sover, dog, deer. The first occurrence is taken as the index of the word the match starts at. For the first three strings we get the indices 1, 4 and 8, respectively, while the string deer is not present.

The first line of your input is the text where you need to look for occurrences. This text consists of space-separated words. Each line after that is a string for which you need to find the index at which it first appears in the previous text, or -1 if it is not present. Note that the index is that of the word where the match begins. The solution is the sum of all indices (-1s included).

Input format

First line is the text (haystack), a space-separated list of words, and each subsequent line is a string (needle). Words and search strings consist of lowercase ASCII letters only.

Output format

The sum of the indices of first occurrences (or -1) for each needle in the haystack.

Sample input

the quick brown fox jumps over the lazy dog
quic
sover
dog
deer

Sample output

12
